# lesson-prep

Инструмент на ПК админа: готовит урок (HLS из MP4) и загружает его в КвестКласс через API импорта. Сервер видео не перекодирует — всё тяжёлое делается здесь (CLAUDE.md, правило 13).

В MVP есть команда `import`. Остальные шаги SPEC §5 (YouTube-бэкап, субтитры, вопросы локальной LLM) — этап 2.

## Установка

Нужны Node 22 и ffmpeg с ffprobe в `PATH` (или пути в настройках). Видеокарта NVIDIA не обязательна: без NVENC используется libx264.

```sh
corepack pnpm install
corepack pnpm --filter @questclass/lesson-prep build
node tools/lesson-prep/dist/cli.js --help
```

## Настройки

`~/.questclass/lesson-prep.json` (или `--config <файл>`):

```json
{
  "server": "https://questclass.duckdns.org",
  "token": "qci_…",
  "encoder": "auto",
  "ffmpeg": "ffmpeg",
  "ffprobe": "ffprobe"
}
```

- `token` — токен импорта из админки («Настройки → Токены импорта»), показывается один раз. Если его нет в файле, он читается из stdin: `type token.txt | lesson-prep import …` или вводится по запросу в терминале. **В аргументах команды токен не принимается** — он попал бы в историю команд и список процессов.
- `encoder` — `auto` (NVENC, если пробное кодирование на видеокарте прошло, иначе libx264), `nvenc` или `x264`.

## Пакет урока

Папка с файлами:

```
lesson.json   описание урока
video.mp4     исходное видео (любой кодек, который читает ffmpeg: H.264, VP9, AV1…)
hls/          готовый HLS; если его нет или видео новее — делается автоматически
images/       картинки вопросов
```

`lesson.json`:

```json
{
  "externalId": "yt-9rj3EcFE3eQ",
  "subjectKey": "math",
  "title": "Логические задачи",
  "lessonDate": "2025-09-03",
  "xp": 100,
  "coins": 350,
  "video": "video.mp4",
  "questions": [
    {
      "key": "q1",
      "text": "Сколько…?",
      "options": [
        { "id": "a", "text": "1" },
        { "id": "b", "text": "2" },
        { "id": "c", "text": "3" },
        { "id": "d", "text": "4" }
      ],
      "correct": "b",
      "image": "images/q1.webp",
      "evidence": { "start": 200, "end": 295, "quote": "…" }
    }
  ],
  "transcript": { "lang": "ru", "source": "youtube", "segments": [{ "start": 0, "end": 4, "text": "…" }] }
}
```

- `externalId` — постоянный id урока: повторный импорт обновляет урок, а не создаёт новый.
- `subjectKey` — ключ существующего предмета (`russian`, `math`, `world`, `reading`, `art`, `craft`…).
- `video` — путь к исходнику относительно папки или абсолютный (по умолчанию `video.mp4`).
- Картинки — только в `images/`, имена из `a-z`, `0-9`, `_`, `-` с расширением `.webp`, `.png` или `.jpg`.
- Вопросы: ровно 4 различных варианта `a`–`d`, `key` неизменен между импортами.

## Команда `import`

```sh
lesson-prep import <папка> [<папка>…] [--config файл] [--server адрес] [--encoder auto|nvenc|x264]
```

1. Проверяет `lesson.json` (до всякой тяжёлой работы; ошибки перечисляются списком).
2. Если нет `hls/master.m3u8` или видео новее, ffmpeg делает HLS: H.264 360p и 480p, AAC, сегменты по 4 с (`hls/master.m3u8`, `hls/360p/…`, `hls/480p/…`). Работа идёт в `hls.tmp/`, готовая папка появляется только целиком.
3. Считает размер и sha256 каждого файла и отправляет манифест (`POST /api/import/lessons`).
4. Догружает только то, чего на сервере нет, частями по 4 МБ с `offset`. После обрыва спрашивает у сервера, сколько байт принято, и продолжает с этого места (до 5 попыток на часть).
5. Завершает медиа: сервер сверяет размеры и sha256 и помечает видео готовым.

Итог по уроку:

- новый урок — черновик;
- черновик — обновляется на месте;
- опубликованный урок — ревизия, которую админ принимает или отклоняет в админке.

Повторный запуск без изменений ничего не перекодирует и не загружает.
