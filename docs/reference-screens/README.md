# Эталонные скриншоты оригинала

Сняты 14.11.2026 с **локального** запуска исходников QuestClass. Использовались мок-вход `local_seedy` и локальная база miniflare с тестовой копией данных (`star-practice`, `testMode` выключен). Все внешние запросы в браузере блокировались, прод не затрагивался.

- `desktop/` — 1440×900; `mobile/` — 390×844.
- Снимки полностраничные, поэтому закреплённое нижнее меню на длинных страницах попадает в середину кадра.
- YouTube и картинки из R2 (`/api/images`) локально недоступны, на их месте пустые блоки.
