# Хостинг с доступом из РФ без VPN (сводка на 14.11.2026)

Метка **[не пров.]** — данные агрегатора или единичного источника, либо источники противоречат друг другу. Это не юридическое заключение.

## Главное
- **Cloudflare, Hetzner и DigitalOcean не годятся** для отдачи видео в РФ. Supabase Cloud, Vercel и Netlify работают ненадёжно.
- **В 2026 году сбоили и российские облака:**
  - Yandex Cloud: 7–11.10.2026 удары дронов по ЦОД, безвозвратно потеряно 2,84% данных клиентов.
  - Beget: 2.11.2026 кибератака уничтожила облачные VPS и S3 вместе с бэкапами.
- Вывод: **бэкап у второго провайдера обязателен**, где бы ни стояло приложение.

## 4. Supabase self-hosted или своё на Postgres
- **Supabase self-hosted:** около 10 контейнеров, нужен VPS минимум 4 ГБ RAM (рекомендуется 8 ГБ). Апгрейды ломают совместимость, поддержка только от сообщества. Для 1–5 пользователей тяжеловато.
- **Свой вариант:** Postgres (или SQLite) + API приложения + авторизация + файлы на диске через nginx (`X-Accel-Redirect`, Range). Хватает 2 ГБ RAM.
- **MinIO** заархивирован 25.04.2026, в новые проекты не брать. Если нужен S3-API на своём VPS, лучше **Garage** (`--single-node`, presigned URL, CORS, lifecycle). Есть ещё SeaweedFS (зрелый) и RustFS (молодой, много уязвимостей).

## 5. 152-ФЗ
- **Своя семья:** закон не применяется к обработке данных физлицом «для личных и семейных нужд» (ч. 2 ст. 1).
- **Чужие семьи:** если сервисом пользуются другие семьи, владелец становится оператором ПДн. Нужны согласия родителей, уведомление РКН и локализация данных в РФ (ч. 5 ст. 18).
- Хостинг в РФ закрывает требование локализации в любом случае.

|---|---|---|---|
| **1** | VPS в РФ под приложение + российский S3 под видео и картинки, видео в MP4 по presigned-ссылкам, ночной `pg_dump` + копия у другого провайдера | ≈1 100–1 400 | сбой облака; нужна копия у второго провайдера |
| **2** | Всё на одном VPS в РФ: приложение, БД, видео на диске через nginx; бэкап через restic/rclone в S3 другого провайдера | ≈1 100–2 000 | единая точка отказа без внешнего бэкапа |
| **3** | Supabase self-hosted на VPS 4/8 | ≈1 850–2 600 | сложность и хрупкость |

Общие правила:
- Не ставить Cloudflare перед сайтом, не использовать зарубежные CDN.
- Регулярно проверять восстановление из бэкапа.
- Видео удалять через N дней после пройденного урока (ретеншн): тогда хранится ≈4–7 ГБ, без ретеншна ≈60 ГБ в год.
