# КвестКласс 2

Семейное учебное приложение: задания с видео и тестами, прогресс, награды, магазин. Новая версия по идее оригинального КвестКласса (ChatGPT Sites), написанная с нуля под свой сервер с доступом из РФ.

- ТЗ: [docs/SPEC.md](docs/SPEC.md)
- Спецификации модулей с чеклистами паритета: [docs/spec/](docs/spec/)
- Эталонные скриншоты оригинала: [docs/reference-screens/](docs/reference-screens/README.md)
- Ресёрч (хостинг, опенсорс): [docs/research/](docs/research/)

Исходники оригинала (`QuestClass-Source/`) и дамп его БД (`ddatabase/`) в репозиторий не входят.
