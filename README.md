# КвестКласс 2

Семейное учебное приложение. Родители (админы) дают детям задания: видеоуроки с вопросами, тесты, домашние дела. Ученики проходят их и получают XP и монеты, а монеты тратят в магазине на образы героя, комнаты и билеты-желания.

Новая версия идеи оригинального КвестКласса (ChatGPT Sites), написанная с нуля под свой сервер с доступом из РФ.

## Что внутри

- **Ученик:** очередь уроков, видеоплеер (HLS) с засчитыванием просмотра, тесты с попытками, дела «Я сделал», серия занятий, награды, магазин, герой и комнаты.
- **Кабинет родителя:**
  - пользователи и «детские» устройства;
  - предметы, задания и вопросы;
  - прогресс с ручным управлением;
  - проверки дел;
  - ручные награды;
  - каталог магазина и выдача желаний;
  - история, оформление, настройки, ключи API.
- **Универсальность:** всё настраивается из кабинета, без правки кода, включая логотип, картинки товаров и звуки. Переменные окружения нужны только для запуска (`PORT`, `DATA_DIR`, `NODE_ENV`).

## Стек

- Node 22, TypeScript, pnpm workspaces.
- API: Hono, Drizzle ORM и SQLite (better-sqlite3).
- Веб: Vite, React 19, TanStack Query.
- Тесты: Vitest, Playwright.
- Деплой: один Docker-контейнер за обратным прокси, до 200 МБ памяти.

## Быстрый старт

```sh
git clone https://github.com/olegmedv/questclass.git && cd questclass
DOMAIN=quest.example.com docker compose -f deploy/docker-compose.example.yml up -d --build
```

Затем откройте `https://<домен>/setup` и введите одноразовый код из лога контейнера. Подробно (без домена, без Docker, бэкап, обновление) — в **[docs/DEPLOY.md](docs/DEPLOY.md)**.

Разработка: `corepack pnpm install`, затем `corepack pnpm dev`.
